# SnapAnemia
Gerçek zamanlı anemi teşhisi sağlayan mobil uygulama geliştirdim. 
Akıllı telefon kamerası ile alınan el görüntüsünü işleyerek alyuvar yapısını analiz eden ölçüm indeksi oluşturdum. 
Rule-based detection algoritmasıyla anemi olasılığını belirledim. 
Doktor ve hastaların verilerini Firebase üzerinde güvenli biçimde saklayıp geçmiş test analizlerine erişim sağladım.
